# Testes Automatizados com Cypress

Projeto de automação de testes E2E desenvolvido com Cypress.

## Sites testados

- [SauceDemo](https://www.saucedemo.com)
- [Serverest](https://front.serverest.dev)

## Testes realizados

### SauceDemo
- Login com sucesso
- Fluxo completo de compra

### Serverest
- Login com sucesso
- Busca de produto
- Adicionar produto ao carrinho
- Acessar carrinho
- Voltar ao home
- Logout

## Tecnologias
- Cypress
- JavaScript

## Como rodar

```bash
npx cypress open
```
